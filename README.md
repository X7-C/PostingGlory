# Posting Glory Test Client

A minimal vanilla JavaScript social media client built for the Noroff API (v2).
This project was built with **functionality first**, using no frameworks.
Some parts of the API handling were reused and adapted from my earlier projects for consistency and faster development.

---

## 📌 Features

### Authentication
- Register new users
- Log in
- Store sessions using `localStorage`
- Logout

### Posts
- View all posts (paginated)
- View single posts
- Create posts
- Edit own posts
- Delete own posts
- React to posts (❤️)
- View reactions count
- Add comments
- View comments

### Profiles
- View any user’s profile
- See all posts from that user
- Follow / Unfollow
- Followers / Following counters
- Open user profiles from posts or comments

### Search
- Search across **all posts**, not only the current page
- Search by:
  - title
  - body
  - author

---

## 🧩 Technologies Used

- **HTML5** — static pages
- **Vanilla JavaScript (ES6 Modules)**
- **PicoCSS** — base styling
- **Custom CSS** — minimal layout & responsiveness
- **Noroff Social API (v2)**
- **Fetch API**
- **localStorage**

No React, no bundlers, no frameworks.
